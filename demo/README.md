# Stable Diffusion 图片生成服务前端

## 项目概述

这是一个基于HTML、CSS和JavaScript开发的前端应用，用于直观演示Stable Diffusion图片生成服务的各项功能。该应用包含以下核心功能：

- 文本生成图片（完整参数模式）
- 简单文本生成图片（快速模式）
- 模型管理（查看SD基础模型和LoRA模型）
- 系统配置查看
- 健康检查

## 技术栈

- HTML5
- CSS3 (Bootstrap 5)
- JavaScript (原生)

## 使用方法

### 1. 启动后端服务

确保您的Stable Diffusion后端服务已启动，并运行在 `http://localhost:8000` 地址。如果后端服务运行在不同地址，请修改 `script.js` 文件中的 `API_BASE_URL` 变量。

### 2. 启动前端服务器

在项目目录中运行以下命令启动本地前端服务器：

```bash
# 使用Python内置服务器
python -m http.server 8080

# 或使用Node.js的http-server
# npm install -g http-server
# http-server -p 8080
```

### 3. 访问前端应用

打开浏览器，访问 `http://localhost:8080` 即可使用前端应用。

## 功能说明

### 图片生成

1. **完整参数模式**：
   - 支持设置详细的生成参数，包括提示词、反向提示词、图片尺寸、推理步数、引导系数等
   - 支持选择SD基础模型和LoRA模型
   - 支持设置LoRA权重和采样器

2. **简单模式**：
   - 仅需提供提示词即可生成图片
   - 其余参数使用默认值

### 模型管理

- 查看系统中所有可用的SD基础模型和LoRA模型
- 刷新模型列表（适用于添加新模型后）
- 查看系统配置信息

### 系统状态

- 检查服务是否正常运行
- 查看服务版本信息

## 错误处理

应用包含适当的错误处理机制，能够友好地提示用户操作错误或服务异常。当后端服务不可用或返回错误时，会显示相应的错误信息。

## 注意事项

1. 确保后端服务已正确启动并运行
2. 确保前端和后端服务的地址配置正确
3. 生成图片可能需要较长时间，具体取决于您的硬件性能
4. 请合理使用生成功能，避免过度请求导致服务负载过高
